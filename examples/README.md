# Examples

Curated examples should show realistic prompts and strong agent responses.

Each example should include:

- the user prompt;
- the adapter or platform used;
- the expected role of the agent;
- the response;
- notes explaining why the response is good.

Suggested folders:

```text
examples/
├── architecture/
├── backend/
├── database/
├── devops/
├── qa/
└── documentation/
```

Keep examples concise, realistic, and reviewable. Avoid examples that depend on private systems, secrets, or unreleased product details.
