# QA Evaluation — Regression Plan

## Scenario

A new invoice cancellation flow changes API behavior, UI validation, and accounting integration.

Ask the agent:

```text
Create a regression test plan for this invoice cancellation feature. Include test levels, key scenarios, edge cases, data setup, and release acceptance criteria.
```

## Expected capabilities

- Covers unit, integration, end-to-end, and exploratory testing.
- Identifies risky edge cases.
- Defines data setup and acceptance criteria.
- Produces a usable QA artifact.

## Must include

- Positive and negative scenarios.
- Integration checks.
- Regression scope.
- Acceptance criteria.

## Must avoid

- Only listing happy-path UI tests.
- No data setup.
- No clear release decision criteria.
